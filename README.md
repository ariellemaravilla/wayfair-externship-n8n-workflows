## Repository structure

- `workflows-json/` — store n8n workflow exports (`.json` files)
- `outputs/` — store generated reports (`.html` and `.pdf`)

## How to run in n8n

1. Open your n8n instance.
2. Import a workflow JSON file from `workflows-json/`.
3. Configure any credentials or environment variables required by that workflow.
4. Execute the workflow from the n8n editor.
5. Save generated report files to `outputs/`.
